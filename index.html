DockPeek vs. DockSwitch

DockPeek (This)

  • Hover-triggered preview
  • See any app's windows
  • Media playback controls
  • Close/minimize windows
  • Global keyboard shortcuts
  • Full-featured & powerful
  • Free & open

DockSwitch (Free)

  • Menu bar click trigger
  • Current app windows only
  • Media controls
  • Close/minimize
  • Local keyboard navigation
  • Lightweight & simple
  • App Store (coming soon)

DockSwitch is a free App Store version for discovery. DockPeek is the full-featured free direct distribution for power users.

System Requirements

macOS 13.0 or later (Intel and Apple Silicon)

Requires Screen Recording and Accessibility permissions for window previews and control.

Installation

  1. Download & Extract: Click the download button above, then double-click DockPeek.dmg to mount it
  2. Drag to Applications: Drag DockPeek.app from the disk image to your Applications folder
  3. Grant Permissions: Open System Settings → Privacy & Security → Accessibility, add DockPeek to the list
  4. Grant Screen Recording: System Settings → Privacy & Security → Screen Recording, add DockPeek
  5. Launch: Open Applications → DockPeek. Click the grid icon in your menu bar, then hover over any Dock app to see its windows

Frequently Asked Questions

Why do I need to grant Accessibility permission?

Accessibility APIs let DockPeek close windows, minimize apps, and control media playback—the features that make it powerful. macOS requires explicit permission for any app that needs these capabilities.

Does DockPeek work with all apps?

Yes. It works with every macOS app—native apps, browsers, terminals, everything. Some full-screen or game apps may not show previews due to their own restrictions, but DockPeek itself is universal.

Is there a free version?

Yes. DockSwitch is a free App Store alternative that shows windows from the current app only. DockPeek is the full-featured free direct distribution for power users.

Can I customize keyboard shortcuts?

Not yet, but it's planned. For now, arrow keys navigate, Return switches, Escape closes the panel, and Cmd+W closes the focused window.

Will DockPeek ever be on the App Store?

No. The App Store's sandbox restrictions prevent DockPeek's core features (hover trigger, global keyboard monitoring, window control). Direct distribution keeps it powerful and unrestricted.

How do I support development?

DockPeek is offered free as a gift to the macOS community. If you find it valuable and want to support future development, donations are always appreciated via our website.
